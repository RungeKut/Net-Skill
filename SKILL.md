# Сети MikroTik: диагностика и настройка скриптами

Корень набора — папка, из которой прочитан этот файл; соседние скиллы —
рядом. База — `knowledge/` (карта — `INDEX.md`). Общие правила —
соседний скилл skill-skill.

**Первым делом:** `git -C <корень> pull --rebase`; конфликт — до работы.

## Железные правила

1. **Сеть — общий ресурс.** Перед изменением правил: второй проверенный
   путь до роутера (`20-01`), `/export` себе (`10-02`); общий роутер —
   только с явного согласия человека (`30-10`). Чтение — без спроса.
2. Счётчики вместо рассуждений (`10-03`): «drop по нулям» значит
   «разрешено»; дошёл ли пакет — conntrack (`10-04`).
3. Проверять из сети пострадавшего (`20-03`); curl — с `--noproxy '*'`
   (`30-06`).
4. Отрицательный результат без контрольного опыта ничего не доказывает
   (`20-04`).
5. В набор — ничего о площадках: адреса, SSID, карты — в `local/` под
   `.gitignore` (`40-03`); примеры — на `192.0.2.0/24`.
6. Правка набора: `git diff` → `python tools/check_docs.py` → коммит →
   push сразу. Автор — публичный, задан для клона; не задан — не
   коммитить.

## Быстрый старт

```python
sys.path.insert(0, "<корень набора>")
from netkit import Router, probe

r = Router("192.0.2.1", user="admin")   # пароль: pw_file=, NETKIT_PW
print(r.cmd("/system resource print"))  # модель и версия
path = r.export("osmotr")               # выгрузка к себе
```

— запись по `00_ПРАВИЛА.md`, строки в `INDEX.md` и `CHANGELOG.md`.
