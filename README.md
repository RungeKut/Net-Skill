# Net-Skill

Набор для работы с сетями MikroTik RouterOS скриптами: диагностика
«нет интернета», фаервол по счётчикам, гостевые и IoT-сети с изоляцией,
Wi-Fi, туннели между площадками, прозрачный прокси-шлюз (mangle →
TPROXY, Xray/VLESS/3x-ui). Скилл для ИИ-агента плюс база знания,
накопленного на живых сетях.

## Установка

```bash
git clone https://github.com/RungeKut/Net-Skill.git "<папка скиллов агента>/net"
```

Рядом нужен скилл skill-skill (общие правила, проверки, хук):

```bash
git clone https://github.com/RungeKut/Skill-Skill.git "<папка скиллов>/skill-skill"
```

Настройка клона (автор коммитов, хук) — skill-skill,
`knowledge/40_СРЕДА/40-01`. Зависимости набора и переменные окружения —
`knowledge/40_СРЕДА/40-01` здесь. Прав администратора не требуется.

## Как устроен

```
net/
  SKILL.md           что читает ИИ, когда берётся за сеть
  knowledge/         база: как вызывать, как работать, что ломается
  netkit/            библиотека: ros, probe, wifi
  templates/local/   шаблон карты площадки (коммитится)
  local/             карты конкретных сетей, выгрузки — НЕ под git
  tools/             обёртка общей проверки перед коммитом
```

## Принципы

1. **Сеть — общий ресурс:** второй путь до роутера, `/export` до правки,
   на общем роутере — только с явного согласия человека.
2. **Осмотр начинается с `/export`,** не с серии `print`.
3. **Измерять, а не рассуждать:** счётчики правил и conntrack.
4. **Отрицательный результат без контрольного опыта** ничего не
   доказывает.

Карта базы — `knowledge/INDEX.md` (есть поиск по симптому), правила
ведения — `knowledge/00_ПРАВИЛА.md` и общий закон в skill-skill.

## Библиотека

```python
sys.path.insert(0, "<корень набора>")
from netkit import Router, probe, wifi

with Router("192.0.2.1", user="admin", pw_file="local/pw.txt") as r:
    print(r.version())           # модель и версия — для applies_to
    path = r.export("osmotr")    # выгрузка к себе
    print(r.counters(chain="input"))
    print(r.connections("protocol=icmp"))

probe.ping("192.0.2.10", "8.8.8.8")             # привязка к источнику
probe.http("192.0.2.10", "http://example.com")  # --noproxy обязателен
probe.route_to("8.8.8.8")                       # куда пойдёт пакет
```

Все функции проверены на живом роутере (RouterOS 7.24.4); знание,
лежащее в основе функции, продублировано в её docstring со ссылкой на
запись базы.

## Данные площадок — в local/, не под git

Репозиторий публичный, а схема сети — готовая карта для того, кто будет
её ломать. Переносимое знание — в `knowledge/` (обезличено), карты
конкретных сетей и личные методички — в `local/` под `.gitignore`.
Шаблон карты — `templates/local/ПЛОЩАДКА-образец.md`. Пароли не кладутся
даже в `local/`: SSH-ключи или временный файл
(`knowledge/40_СРЕДА/40-03`).
