# Установка и окружение

## Установка набора

Клон и есть папка скилла:

```sh
git clone https://github.com/RungeKut/Net-Skill.git "<папка скиллов агента>/net"
```

Рядом нужен skill-skill — общие правила, проверки и хук:

```sh
git clone https://github.com/RungeKut/Skill-Skill.git "<папка скиллов>/skill-skill"
```

Настройка клона (автор коммитов, хук, стоп-лист) — skill-skill,
`knowledge/40_СРЕДА/40-01`. Коротко:

* автор коммитов **для клона**, без `--global`:
  `git config user.name/user.email`; не задан — не коммитить;
* хук: `git config core.hooksPath ../skill-skill/hooks`;
* локальный стоп-лист `tools/stoplist.txt` завести руками — приметы
  площадок этой машины, под git он не попадает.

Установщиков нет: ни junction, ни переменных `*_HOME`, ни путей
конкретного агента. Корень набора — папка, в которую склонирован
репозиторий; код ищет свои ресурсы от `__file__`, соседний скилл —
`<родитель корня>/<name>`.

## Что нужно на машине

| Что | Зачем | Проверка |
|---|---|---|
| OpenSSH 8.4+ | `SSH_ASKPASS_REQUIRE=force` для пароля из скрипта | `ssh -V` |
| `scp` | забрать выгрузку конфига | идёт с OpenSSH |
| PowerShell 5.1 | проверки TCP и DNS с привязкой к источнику | есть в Windows |
| Python 3.x | `netkit`, проверки набора | `python -V` |
| curl | HTTP-проверки | идёт с Git for Windows |
| Git Bash | оболочка для скриптов `.sh` | |

**Прав администратора не требуется.** Это принципиально: приёмы набора
подобраны так, чтобы работать без них
([20-03](../20_ПРИЁМЫ/20-03_проверка_из_нужной_сети.md)).

Чего **нельзя** без прав администратора, и на что это влияет:

* менять метрики интерфейсов и добавлять маршруты — поэтому интерфейс
  выбирается привязкой к адресу источника;
* `arp -d` — запись остаётся, см.
  [30-07](../30_ГРАБЛИ/30-07_arp_d_без_админа.md);
* устанавливать драйверы.

Что **можно** без прав администратора: добавлять профили Wi-Fi
(`netsh wlan add profile ... user=current`), подключаться и отключаться.

## Переменные окружения (необязательные)

* `NETKIT_PW` — пароль роутера для `netkit.ros.Router`, если не задан
  через `password=` или `pw_file=`. Умолчание: переменной нет —
  используется SSH-ключ или askpass не запускается вовсе.
* `SSH_ASKPASS`, `SSH_ASKPASS_REQUIRE`, `DISPLAY` — выставляются кодом
  `netkit/ros.py` самим, задавать руками не нужно
  ([10-01](../10_API/10-01_ssh_в_routeros_неинтерактивно.md)).

`http_proxy` и родственные — не настройка набора, а ловушка: curl молча
уходит в прокси ([30-06](../30_ГРАБЛИ/30-06_curl_уходит_в_прокси.md)).

## Ловушки окружения

**Кодировка вывода PowerShell.** Консоль Windows отдаёт CP866. Скрипты
`.ps1` с кириллицей сохранять **с BOM**, иначе PowerShell 5.1 прочтёт их
как ANSI и выведет мусор. В `.gitattributes` для `.ps1` задан CRLF.

**Кириллица в именах интерфейсов.** Имя вроде `Беспроводная сеть`
передаётся в `netsh` как есть, но в Git Bash требует аккуратных кавычек.
Надёжнее работать по `InterfaceIndex`.

## Чем подтверждено

Весь цикл работы (SSH к двум роутерам, переключение Wi-Fi между четырьмя
сетями, проверки TCP/DNS/HTTP с привязкой) отработал на учётной записи
без прав администратора. Установка клоном с общим хуком — как у всех
наборов по стандарту skill-skill.
