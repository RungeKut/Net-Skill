# local/ — данные площадок, вне git

Это шаблон, лежит в `templates/local/` под git. Папка `local/` в клоне
создаётся по нему и **игнорируется целиком**: под git не попадает ни
один её файл.

## Почему

Репозиторий публичный. Схема сети — готовая карта для того, кто будет
её ломать: адреса, SSID, пробросы портов, состав VPN, имена людей.

Переносимое знание («как работает RouterOS», «где грабли») живёт в
`knowledge/` и обезличено. Здесь — только то, что относится к конкретной
сети и никому другому не нужно.

Признак, по которому отличить одно от другого: **запись, из которой
нельзя убрать конкретные адреса, не сломав смысл, — данные площадки.**

## Что класть

* `<имя-площадки>.md` — карта по образцу `ПЛОЩАДКА-образец.md`
  (скопировать его из `templates/local/`);
* личные методички по своей инфраструктуре — то, что не обезличить без
  потери смысла;
* `*.rsc` — выгрузки конфигов;
* пометки о незакрытых задачах.

## Чего не класть даже здесь

**Пароли.** Файл с паролем для скриптов создаётся на время работы и
удаляется после. Лучше — SSH-ключи, тогда он не нужен вовсе.

## Правило

Изменил сеть — в тот же заход обнови карту. Устаревшая карта хуже её
отсутствия: по ней принимают решения.

Подробнее — `knowledge/40_СРЕДА/40-03_локальные_данные_площадок.md`.
